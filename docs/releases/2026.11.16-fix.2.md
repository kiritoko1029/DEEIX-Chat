# v2026.11.16-fix.2 — 本轮联网结果汇总到一处

## 新增

- **搜索结果汇总入口**：一轮回答里所有联网搜索与读链接的结果，现在合并成回答上方一行「搜索到 N 个网页 / 阅读了 N 个网页」的胶囊，带前三个站点图标。以前要在过程轨迹里逐个展开工具调用查看，现在一处看全。
- **右侧面板展开**：点击这行胶囊，会在右侧工作区打开「联网搜索结果」面板（与交互组件、代码预览共用同一个可拖拽调宽的面板），列出本轮去重后的全部网页：站点图标、站点名、标题、发布时间、摘要。面板打开时聊天区自动让出空间，移动端为全屏覆盖；关闭面板或打开别的右侧内容即可收起。

## 修复

- **搜索结束与展开后计数跳变**：此前回答结束时胶囊显示「搜索到 4 个网页」，点开「执行完成」后变成 13 个。原因是消息列表摘要把工具调用的展示投影（`output_presentation`）连同完整输入输出一起裁掉，折叠状态只能从被截断的输出预览里数到 4 个 URL，加载完整轨迹后才恢复成 13。现在摘要在裁剪时保留展示投影，折叠与展开使用同一份来源数据，计数稳定一致。
- 前端来源统计优先使用该展示投影，不再在展开后混用原始载荷，避免数字随加载状态变化。
